# Nazar Imbiss & Bäckerei – Website

Schulprojekt von Artur Nuraliev, Klasse KA251  
Friedrich-List-Berufskolleg, 2024/2025

## Beschreibung
Offizielle Website für das Restaurant Nazar Imbiss & Bäckerei in Bad Godesberg.  
Entwickelt mit HTML5, CSS3 und Vanilla JavaScript.

## Funktionen
- Speisekarte mit Warenkorb-Funktion
- Responsive Design für alle Geräte
- Standorte mit Google Maps Links
- Kontaktformular mit Validierung
- Cookie-Banner

## Technologien
HTML5 · CSS3 · JavaScript · GitHub Pages
